## 3-Line Justification Matrix

1. **Cost:** Utilizing WooCommerce on WordPress / custom lightweight PHP e-commerce architecture eliminates licensing fees ($0 core cost) and allows full integration of free open-source database tools under XAMPP without recurring subscription expenses.
2. **Customization:** WooCommerce/PHP provides full granular control over size variant rules (enforcing size selection prior to add-to-cart), stock zero blocking logic, custom EMS shipping calculations, and local Bangladeshi Mobile Banking (bKash/Nagad) gateways.
3. **Timeline:** The modular PHP database structure enables complete deployment, seed configuration from JSON data, notification simulation, and multi-gateway testing well within the strict 1 hour 30 minute assessment timeline.
